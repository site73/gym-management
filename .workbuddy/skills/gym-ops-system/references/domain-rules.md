# 领域规则与数据口径

## 1. 角色与权限

| 角色 | 账号示例 | 可见范围 |
|---|---|---|
| 会员 MEMBER | `member1` / `member2` | 仅本人：会籍、预约、场地、课表、体测 |
| 教练 COACH | `coach1`~`coach3` | 本人授课课表、本人课程学员名单、核销本人课程签到 |
| 店长 MANAGER | `manager` | 全店业务：排课、收费、报表、场馆、场地预约、课表 |
| 管理员 ADMIN | `admin` | 店长权限 + 系统管理（重置演示数据、接口日志） |
| 超级管理员 SUPER_ADMIN | `superadmin` | 以上 + 账号管理（查看 / 重置密码 / 启停） |

越权一律 403，未登录 401。`scope`、`memberId`、`coachId` 由服务端归一化，前端传什么都改不回越权数据。

## 2. 状态机

- **会员**：`potential` 潜在 → `active` 有效 → `expired` 过期 / `frozen` 冻结
- **会籍**：`active` / `frozen` / `expired`；冻结期不计入有效期
- **预约**：`booked` 已约 → `checked_in` 已签到 / `no_show` 爽约 / `cancelled` 已取消
- **课程**：`published` 已发布 / `full` 满员 / `ongoing` 进行中 / `finished` 结束 / `cancelled` 下架（软删除）
- **订单**：`pending` → `paid` / `abnormal` 异常 / `refunded`
- **场地预约**：`booked` / `cancelled` / `finished`

## 3. 十条系统规则

| 规则 | 内容 | 关键参数 |
|---|---|---|
| SYS-R1 | 仅有效会籍可约课；过期返回"会籍过期" | — |
| SYS-R2 | 冻结期不计有效期，冻结期间禁止约课 | — |
| SYS-R3 | 预约数 ≤ 容量；同会员同时间 1 个预约；教练/场地/时间冲突则拒绝 | — |
| SYS-R4 | 累计爽约 ≥ 3 次 → 限制预约 7 天 | N=3, 7 天 |
| SYS-R5 | 结课扣减 1 次私教课；余额 0 禁止排课 | — |
| SYS-R6 | 到期前 7 天触发续费提醒（每日扫描） | D=7 |
| SYS-R7 | 连续 4 周未到店 或 近 30 天爽约率 > 30% → 高风险 | 4 周 / 30 天 / 30% |
| SYS-R8 | 爽约概率 > 0.6 → 提醒；满员则释放名额给候补 | T=0.6 |
| SYS-R9 | 办卡 30 天内到店 < 2 次 → 生成跟进任务 | 30 天 / 2 次 |
| SYS-R10 | 私教提成 = 当月课消 × 比例（店长配置） | 比例可配 |

参数外置在 `rule_config` 表，改阈值不改代码、不发版。

## 4. 数据口径

- **爽约率** = 近 30 天爽约次数 / 近 30 天预约次数
- **活跃会员** = 近 30 天至少 1 次签到的会员数
- **体验转化率** = 期内办卡人数 / 期内体验人数
- **流失率**（月）= 当月到期未续费 / 月初有效会员
- **剩余名额** `remaining = capacity - booked_count`
- **有效预约** = `status in ('booked','checked_in')`

## 5. 必须闭合的两条账

1. **名单 ⇄ 余位**：`booked_count == 该课有效预约数`。已取消不进名单、不占余位。
   破坏这条会导致"显示 15/15 已满、名单 0 人"。
2. **课表 ⇄ 业务数据**：周课表是只读聚合视图，条目全部来自各模块契约，不另存一份。

## 6. 场馆模型

4 个私有场馆 + 1 个公共区域：

| 编号 | 场馆 | 类型 | 容量 | 时费 |
|---|---|---|---|---|
| V01 | 私教 A 室 | 私有 | 1 对 1 | ¥80 |
| V02 | 私教 B 室 | 私有 | 1 对 1 | ¥60 |
| V03 | 瑜伽小班室 | 私有 | 8 | ¥50 |
| V04 | 力量训练室 | 私有 | 6 | ¥40 |
| V05 | 公共自由训练区 | 公共 | 20 | 免费 |

私有场馆仅对有效会籍开放；公共区域不限；维护中一律不可约；单次最长 4 小时；同场地时段不可重叠。
