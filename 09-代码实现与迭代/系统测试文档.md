# 健身房运营管理系统 测试文档

> 版本：v2.0（集成版：登录 + 单页 + 全功能合并）
> 被测系统：Spring Boot 3 + MySQL 8.0 后端 + 统一单页前端（登录后按角色进入会员端 / 门店后台）
> 本文档：测试策略、用例设计、缺陷记录、执行结果与复跑方法

## 一、测试策略（七层防护）

| 层次 | 载体 | 关注点 | 数量 |
|---|---|---|---|
| 单元测试 | JUnit 5 + Mockito | 业务规则、权限判定、算法阈值、教练权限隔离、**周课表聚合（11 项）** | 67 |
| 架构守卫 | ArchUnit | 模块边界、依赖方向、Controller 不直连仓储 | 3 |
| 行为驱动验收 | Cucumber（读取 05 目录的 `.feature`） | 关键业务规则可执行 | 18 |
| 集成测试 | `verify/integration-test.js`（真实 HTTP，自带数据复位） | 登录、权限、选课退课、排课、注册、教练、场地预约、报名名单、**账号管理（16 项）**、**周课表（16 项）** | 130 |
| 前端静态检查 | `verify/frontend-check.js` | 按钮无响应类缺陷（未定义函数 / 无引号 / 元素缺失 / 接口不存在 / **未声明的常量引用**） | 6 |
| 真实浏览器测试 | `verify/browser-test.js`（Playwright + Edge） | 真实点击有响应、身份登录、左侧导航、二维码弹窗、搜索、扫码核销、场地预约、教练端、教练/场馆/场地预约管理、分页与名单弹窗、**周课表三视角与课表视图切换（24 项）**、**账号管理（7 项）** | 109 |
| 二维码结构校验 | `verify/qr-check.js` | 生成的二维码结构合法、内容可反解还原 | 5 |

> **"点击无响应"的防护是双保险**：静态检查在提交前拦截（不依赖运行环境），浏览器测试在运行时验证真实交互。

### 关键验证点

- **认证与权限**：未登录 401；会员越权 403；伪造 memberId 被强制为本人；回调接口免令牌放行（真实支付平台不携带前端令牌）。
- **登录后路由**：会员 → 会员端（选课 / 退课 / 签到）；店长 → 门店后台（含**课程管理**，可排课）；管理员 → 再额外出现"系统管理"（数据重置）。
- **排课权限**：会员调用排课接口返回 403；店长与管理员均可排课、改课、下架、上架。
- **自愿选课 / 退课**：会员只能作用于本人（伪造 memberId 被服务端改写）；重复选课幂等；重复退课 409。
- **会员自助注册**：免登录接口，一次事务内创建「登录账号 + 会员档案 + 角色绑定」，会员编号自动生成（M001…），注册即登录。
- **会员 ↔ 课程联动**：店长选中会员后可代客约课；课程卡展示已报名名单与余位，随预约数据实时刷新。
- **前端结构**：左侧导航 + 独立页面（会员 3 页 / 门店 8 页），按角色渲染菜单；同一时刻只显示一个页面。
- **身份登录**：先选身份再输账号；身份与账号角色不符时拦下并提示。
- **扫码签到**：会员端出示二维码（内容 `GYM-CHECKIN:{预约号}:{会员号}`），门店扫码核销；重复核销返回状态冲突。
- **二维码质量**：生成器输出经黑盒反解校验（结构特征 + 格式信息 BCH + 反交织还原原文），v1/v2/v4/v7 全部一致。
- **教练权限隔离**：教练可登录并用专属界面，但排课、场馆维护等门店接口一律 403；只能查自己课程的名单与核销自己课程的签到。
- **场地预约**：同一场地时段不可重叠；私有场馆仅对有效会籍开放、公共区域不限制；单次最长 4 小时；维护中的场馆不可预约。
- **报名名单**：门店后台与任课教练可查某课全部报名会员（含姓名与编号），会员与非本课教练 403。
- **场地预约（浏览器实测）**：会员可选场馆、提交预约、查看与取消；同场地同时段被拒；门店可代客预约。
- **教练端（浏览器实测）**：教练登录后导航仅 2 项、看不到门店菜单、课表只含本人课程、学员名单可查。
- **前端静态检查已扩展至 6 项**：新增 FE-006「引用的全局常量均已声明」，用于拦截
  `XXX_CN is not defined` 这类会导致整段渲染中断、但语法检查发现不了的运行时错误。
- **按钮响应**：41 个内联处理器全部指向已定义函数，浏览器实测全部有响应。
- **幂等性**：重复约课 / 重复回调 / 重复启动（账号初始化）均幂等。
- **重启健壮性**：连续两次重启后端均正常启动，账号无重复。
