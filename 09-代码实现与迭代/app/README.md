# Node 参考实现（备选，非主系统）

> **本项目已完成集成：日常演示与交付请使用统一系统。**
>
> | | 主系统（推荐） | 本目录（参考实现） |
> |---|---|---|
> | 入口 | `http://127.0.0.1:8080/`（统一页面，登录后按角色进入会员端 / 门店后台） | `http://127.0.0.1:3111/` |
> | 代码 | `../../08-系统结构与代码设计/backend`（Spring Boot + MySQL） | `./`（Node 零依赖） |
> | 数据 | MySQL 库 `gym`（Flyway 迁移管理） | 本地 JSON 文件 `data/db.json` |
>
> ⚠️ **两套数据互不相通**：在 3111 里约的课不会出现在 8080。

## 为什么保留

本目录是最早的**零依赖可运行实现**，用于在没有 JDK/Maven/MySQL 的环境下验证业务规则。
它的业务规则语义（SYS-R1…R10）与主系统保持一致，可作为**对照实现**排查规则理解偏差。

## 运行

```bat
set "PATH=E:\dev\nodejs;%PATH%"
cd /d "E:\WorkBuddy\健身房管理业务\09-代码实现与迭代\app"
node server.js          :: 默认 http://127.0.0.1:3111
node smoke.js           :: 接口冒烟（18 项）
```

配套的 `.feature` 执行器位于 `../verify/run.js`（读取 `05-测试用例与测试计划/features`，非副本）。
