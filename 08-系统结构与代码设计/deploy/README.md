# 环境启动脚本（副本）

本目录是 `E:\dev` 下启动脚本的**版本化副本**，用于防止 E 盘环境被清理后脚本丢失。

| 文件 | 作用 |
|---|---|
| `start-system.cmd` | **一键启动整套系统**（双击运行）：MySQL → 后端 → 自动打开浏览器 |
| `start-system.js` | 一键启动器的实现（Node）。含中文路径、就绪等待、失败回退到 local 模式、日志诊断 |
| `start-mysql.cmd` | 单独启动便携 MySQL（独立窗口 + 就绪检测 + 失败时暂停并显示原因） |

## 为什么需要副本

实际运行时脚本必须放在 `E:\dev` 下（脚本内的路径、以及双击运行的便利性都依赖该位置）。
本目录仅作**备份与版本追溯**：一旦 `E:\dev` 被清理，把这三个文件复制回 `E:\dev` 即可恢复。

```bat
copy /Y "E:\WorkBuddy\健身房管理业务\08-系统结构与代码设计\deploy\*.cmd" E:\dev\
copy /Y "E:\WorkBuddy\健身房管理业务\08-系统结构与代码设计\deploy\start-system.js" E:\dev\
```

## 设计要点（踩过的坑）

| 坑 | 正确处理 |
|---|---|
| `.cmd` 用 **LF 换行**，`goto`/标签解析异常 | 必须用 **CRLF** |
| `.cmd` 带 **UTF-8 BOM**，首行 `@echo off` 失效 | 不写 BOM；内容尽量保持 ASCII |
| 脚本内含**中文路径**易因编码损坏 | 含中文路径的逻辑放在 Node（`.js` 为 UTF-8，天然安全），`.cmd` 只做薄壳且全 ASCII |
| `start "" /B` 启动的进程**没有独立窗口**，父窗口一关就被回收 | 用 `start "窗口标题" exe ...`（第一段引号是标题） |
| 脚本没有 `pause`，出错时窗口一闪而过看不到原因 | 失败分支加 `pause` |
| Node 里把标题**连引号一起**传给 `spawn`，会被二次转义 | 用 `shell: true` + 自建命令行字符串 |
| MySQL 启动慢，脚本不等待就继续 | 轮询 `mysqladmin ping`，最多 40 秒；超时打印日志并回退 local 模式 |
