# 答辩展示资料

| 文件 | 用途 |
|---|---|
| **`健身房运营管理系统答辩.pptx`** | 正式 PPT，22 页，学术风（蓝白克制） |
| **`展讲话稿.docx`** | 逐页讲稿（Word，可直接打印带上台） |
| **`展讲话稿.md`** | 讲稿源文件（版本管理） |
| `STORY.md` | 内容大纲：分章、Hero 页、节奏曲线、每页版式与数据来源 |
| `build/` | PPT 生成脚本（`ppt_lib.py` 框架 + `ppt_build*.py` 页面 + `main.py` 组装与自检） |
| `assets/` | PPT 引用的图片（项目真实产出的流程图、架构图、库表总览） |

## 内容结构（22 页）

- 封面 · 目录
- **01 业务理解与需求分析**（第 3–6 页）
- **02 系统设计与架构**（第 7–10 页）
- **03 关键实现与业务规则**（第 11–16 页，含两项创新点）
- **04 质量保障与测试**（第 17–19 页）
- **05 总结与展望**（第 20–21 页）
- 结束页

## 讲稿怎么用

- 时间总表在讲稿第二节，合计约 **19 分钟**；压缩方案在第五节。
- 每页都给了「可直接念的台词」，以及**有演示 / 无演示**两套做法。
- 第六节准备了 10 个常见提问的应答要点，建议提前过一遍。
- 第七节是上台前的准备清单（含账号、数据重置、备用方案）。

## 修改 PPT 后重新生成

```bat
cd /d "E:\WorkBuddy\健身房管理业务\10-展示汇报\健身房运营管理系统答辩"
C:\Users\MSI_NB\.workbuddy\binaries\python\envs\default\Scripts\python.exe build\main.py
```

脚本会自动完成两件事：生成 PPT，并做**版面溢出自检**（按全角字符估算每行容量，
发现文字超出卡片会在控制台列出页码与超出比例）。修改文案后重跑即可确认没有溢出。

> 说明：本机没有安装 LibreOffice，无法导出图片预览；版面正确性由上述自检脚本保证。
> 需要在 PowerPoint / WPS 里打开确认效果时，直接双击 pptx 即可。
