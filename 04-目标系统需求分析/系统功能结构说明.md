# 系统功能结构说明

> 所属阶段：第四阶段（目标系统需求分析报告）
> 来源：业务结构 B1–B8 → 系统功能模块 M1–M8，加系统支撑 M0

## 一、模块结构

| 模块 | 对应业务板块 | 功能点 | 关联需求 |
|---|---|---|---|
| M0 系统支撑 | 全角色支撑 | 用户与权限、**超级管理员账号管理（查看/重置密码/启停）**、两步身份登录、按角色导航、列表分页与搜索、基础数据（字典/课程目录/器材/教练/场馆）、日志审计、**演示排课对齐本周** | REQ-M0-001~011 |
| M1 会籍管理 | B1 | 会员档案、办卡、续费、冻结/解冻、过期处理、合同管理 | REQ-B1-001~005 |
| M2 会员服务 | B2 | 通知提醒、跟进任务（新会员/高风险）、跟进记录 | REQ-B2-001~002 |
| M3 课程与排课 | B3 | 课程管理、排课（管理员/店长）、冲突检测、发布与名额、候补队列、**教练档案与教练端（课表/学员名单/核销签到）**、**周课表视图（会员/教练/门店三视角，列表 ⇄ 课表切换）** | REQ-B3-001~008 |
| M4 预约与签到 | B4 | 约课校验、自愿选课与退课、预约/取消、**二维码扫码签到（凭据+门店核销）**、前台代签、爽约判定、**课程报名名单** | REQ-B4-001~008 |
| M5 收费与财务 | B5 | 订单/支付、续费、课包核销、提成核算、对账、续费提醒 | REQ-B5-001~006 |

| M8 报表与预警 | B8 | 经营报表、流失风险评分、爽约预测、预警任务、工单看板 | REQ-B8-001~009 |

## 二、模块关系

- M3 → M4：教练与排课为签到核销提供归属关系（教练只能核销本人课程）。
- M6 → M4：场地与课程同为可占用的时段资源，冲突校验复用同一思路（R3）。
- M1/M3 → M4：会籍有效性与排课为约课签到提供前置条件。
- M4 → M5/M7：签到与上课产生收费/核销与体测数据。
- M1 → M5：办卡续费产生订单。
- M2/M5/M7 → M8：汇总为报表与预警。
- M0 支撑全部模块。

## 三、前后端形态

- **会员端**：注册登录、选课/退课、扫码签到（出示二维码）、场地预约、付费、查看体测与记录、接收提醒、**我的周课表（本人课程 + 本人场地预约）**。
- **教练端**：我的周课表（本人授课 + 全店场馆占用）、授课课程列表、学员名单、核销签到（仅本人课程）。
- **门店端（Web 管理后台）**：M1–M8 全部管理功能，外加教练管理、场馆管理、场地预约管理、课程报名名单，**周课表（全店课程表 + 场馆占用课表，可切换列表/课表视图）**，按角色控制可见性；超级管理员额外拥有账号管理。
- **服务端**：业务服务、规则引擎（R1–R10）、定时任务（评分/提醒/结算）、消息推送。

## 四、边界声明

本模块结构仅覆盖业务基线范围内的功能；多门店连锁、器材供应链、财务总账、硬件门禁、直播课不在本结构内（见《业务基线 V1.0》范围外项）。
